# Специфіка по типу сторінки (доповнює rules/requirements.md; структури H1-H3 - у файлах поруч)

Структури: `home.md` (3 варіанти, Template #1 найповніший, дефолт для головної), `app.md`, `bonus.md`, `login.md`, `payment.md`.
Це каркас. Перед використанням звірити з 3+ конкурентами з ТОПу і унікалізувати заголовки.

| Тип | Списки (2-5 разів, `<ol>` для кроків) | Таблиці (2-4) | Обов'язкові теми FAQ |
|---|---|---|---|
| Home | `<ul>` бонуси/плюси-мінуси, `<ol>` реєстрація, `<ul>` платежі, `<ul>` мобайл | Quick Facts, Bonus Conditions, Payment Methods | легальність, бонус, виводи |
| Login | `<ol>` вхід, `<ol>` відновлення пароля, `<ul>` помилки входу / 2FA | Quick Facts входу (дані, відновлення, 2FA, методи), сумісність пристроїв | забув пароль, верифікація |
| App/APK | `<ol>` Android, `<ol>` iOS, `<ul>` функції/обмеження (по 4-8 пунктів) | сумісність (ОС, розмір, RAM), Quick Facts застосунку | технічна проблема (установка/оновлення/сумісність) |
| Bonus | `<ol>` активація, 2x `<ul>` умови/право на бонус | Bonus Conditions (вейджер, мін. депозит, макс. виграш, строк, ігри), Quick Facts | вейджер або виведення |
| Payments | `<ol>` депозит/вивід, `<ul>` KYC-документи, `<ul>` валюти/правила | Deposit methods, Withdrawal methods, Quick Facts (KYC, ліміти, крипта) | KYC або затримка виводу, конкретний метод по назві |
| Службові (Affiliates, Terms, Privacy, Cookies, Contact, About, RG) | `<ul>/<ol>` 3-7 пунктів | таблиця за темою (напр. тарифи RevShare, типи cookies, час відповіді по каналах) + опційно `<dl>` | за темою |

Службові сторінки: метадані першими (TITLE 48-58 символів, бренд в кінці через `|`/`-`/`:`; DESCRIPTION 145-158 символів, бренд один раз не на початку, без "best/amazing"). Блупринт на вибір: A аналітичний (Affiliates, Terms, RG), B запит-рішення (Contact, Help, Privacy), C корпоративний/комплаєнс (About, Cookies, Security). 4-6 H2, 2-4 H3. Affiliates обов'язково покриває: моделі комісій (RevShare, CPA, hybrid, negative carryover), cookie і атрибуцію, дозволені/заборонені джерела трафіку, виплати і мінімуми, матеріали і менеджера.
