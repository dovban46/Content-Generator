# Редагування існуючих текстів: процес

Старі сторінки клієнта вважати недосконалими за замовчуванням: шукати і виправляти помилки.

## Цикл
1. Клієнт кладе старий код у `edit/input/content-old.txt` (або дає в чат) + семантику сторінки. Чогось бракує (код не оновлений, немає ключів) - СТОП, повідомити, не гадати.
2. Читати `rules/requirements.md` (+ `rules/wp-format.md`, якщо старий код у WP-блоках).
3. Аналіз: 3+ конкуренти з ТОПу по бренду, структура, ключі, сліди, факти.
4. Писати ПОВНИЙ новий код (не diff) у `edit/output/content-new.html`. "Зберегти результат" - перейменувати під слаг бренду перед наступним сайтом.

## Що перевіряти і чистити
- Ключі: переспам (2-3 в абзаці) розосередити, не видаляти; рахувати standalone-входження бренду ДО і ПІСЛЯ; розрив між згадками <= ~20% тексту; варіанти бренду брати зі списку клієнта.
- Сліди: `<strong>` на ключах/бренді, "'s" при бренді, тире, криві лапки (прогнати `ord(ch) > 127`), голі домени, застарілі роки, фальшиві "we tested", шаблонні абзаци, що могли кочувати між сайтами клієнта (переписати унікальніше).
- Факти: звіряти КОЖНУ цифру зі `data/facts/`; пряме заперечення факт-листа виправляти (напр. "e-wallets missing" при наявних Skrill/Neteller). Значущий факт з факт-листа, якого немає в тексті, додати (напр. блокування ACMA 2019: коротко, 1-2 місця, без паніки). Без факт-листа - правити за здоровим глуздом, без повного ресерчу, якщо не критично.
- Структура: порушення ієрархії H1-H3, H2->H3 без абзацу, 2+ заголовки підряд без ключа. Правило /go/: ніколи не видаляти `/go/`-посилання (рядок Official Website лишається посиланням).
- Списки: прозові кроки/умови (жирні лейбли в `<p>`) конвертувати в `<ol>/<ul>` по одному реченню на пункт, 2-5 на сторінку. Крапка в кінці `<li>` - не слід.
- Заголовки таблиць "Verified Platform Data" та подібні замінити простішими ("Detail", "What X Offers"). Фото: лише звірити alt із секцією.
- Не чіпати: шорткоди, TOC-навігацію, внутрішню перелінковку клієнта.
- Schema FAQ додавати завжди (`itemscope` на існуючі `h3`+`p`, обгортка `wp:html`).
